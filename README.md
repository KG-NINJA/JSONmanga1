# 4コマ投稿設計キット

4コマの構成・登場人物・場面を入力し、JSONと日本語の制作プロンプトを書き出す静的ツールです。画像生成、AIへの接続、自動投稿、決済、売上集計の機能は含みません。

## 使い方

1. `index.html`、`style.css`、`app.js`を同じフォルダに置き、`index.html`をブラウザで開きます。インストール・アカウント・APIキーは不要です。
2. 共感・問題解決・ギャグの作例を選びます。読み込みは現在の入力を置き換えます。
3. タイトル、2人の名前と外見、4つの場面を編集します。人物Bは動物などのキャラクターでも構いません。
4. 「JSONとプロンプトを生成」を押します。4コマすべてに内容が必要です。
5. コピー、またはJSON／TXT保存を使います。プロンプトをお使いの画像制作ツールや制作担当者に渡してください。

入力はブラウザ内だけで処理し、外部に送信しません。ページを閉じると入力は失われます。閉じる前にファイルを保存してください。JSONを読み戻すインポート機能はありません。保存したJSONはテキストエディタで編集でき、各場面を入力欄へ戻せます。

自動コピーを許可しないブラウザでは出力を選択します。Ctrl+C／⌘Cや端末のコピーメニューを使用できます。ダウンロードに対応しない端末ではコピーしてテキストファイルへ保存してください。

## 収録作例

| 構成 | タイトル | 内容 |
|---|---|---|
| 共感 | 最初の一行 | 書けずに悩むアオが、ハルの下書きを見て書き始める |
| 問題解決 | 鍵の帰る場所 | ユイとソラが鍵の置き場所を決め、朝の探し物を減らす |
| ギャグ | 集中の予約席 | 仕事環境を整えたレンのキーボードで、猫のモチが熟睡する |

作例はこのキットのために作成した架空の物語です。人物や場面を自分の企画に合わせて編集してください。生成画像の一貫性や文字の正確さを保証するものではありません。画像制作サービスの利用料は別途、そのサービスの条件に従います。

## 入力と出力

- タイトル100文字、名前各40文字、外見各400文字、場面各1,000文字まで（JavaScriptの文字列長で計数）。
- 空欄・空白だけの入力、4コマ以外のデータ、未知の構成を拒否します。
- JSONは `schema_version`、`title`、`format`、`layout`、`template`、`characters`、`panels` を持ちます。
- 入力を変更した後は古い出力を消去し、再生成するまでコピー／保存を無効にします。
- HTMLとして入力を挿入せず、JSON文字列とテキスト欄へ書き出します。

## ファイル

- `index.html`: 日本語の入力・出力画面
- `style.css`: 画面幅に応じたスタイル
- `app.js`: 3作例、入力検証、JSON・プロンプト生成、コピー・保存
- `tests/app.test.cjs`: Node.js標準テスト。製品の利用にNode.jsは不要

外部フォント、CDN、外部スクリプトへの依存はありません。3つの実行用ファイルをGitHub Pages等へそのまま公開できます。

## カスタマイズの相談

画面にはKGNINJAのXプロフィールにつながる相談窓口を設置しています。入力フォーム、出力文面、配色などの小規模な調整を5,000円からの見積りとして案内します。対応範囲・総額・納期・支払い方法は個別に合意する想定で、この画面から注文や決済は成立しません。画像生成・自動投稿の導入はこの調整サービスに含めていません。
